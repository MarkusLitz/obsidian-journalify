# Security Policy

## Reporting a Vulnerability

If you discover a security or privacy issue in **Journalify**, please do not open a public issue with exploit details. Instead, report it privately via GitHub Security Advisories on this repository or contact the maintainer directly.

Journalify runs locally inside Obsidian without backend servers, telemetry, or third-party tracking. Optional weather lookups communicate exclusively with the public Open-Meteo API over HTTPS when enabled and triggered by the user.
